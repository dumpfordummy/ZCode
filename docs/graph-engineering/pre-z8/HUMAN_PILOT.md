## Task script

1. **First task:** with provider and disposable workspace already selected, create an Agent-assisted task without raw JSON. Locate its generated steps, request/context preview and evidence policy. Target: under three minutes of operator interaction, excluding model time. The participant must explain why completion/approval is not a machine-test pass.
2. **Native interaction:** start only after reviewing workspace/model/permission context. Locate and answer a native permission and question in the exact existing conversation; review the separate final Graph approval. The participant must distinguish all three responses and what the approval can admit.
3. **Checks and diagnosis:** on the supported standard VSTest fixture with dependencies prepared, select targets/frameworks, review exact Build/Test commands and source/output coverage, save, then explicitly calibrate. Target: under ten minutes of operator interaction; separately record command/restore wall time. With an intentional independent assertion failure, identify the step, original report and safe next action within sixty seconds. Repeat with invalid/zero-test evidence and explain why it cannot authorize repair or pass.
4. **Reuse:** import a reviewed sequential template file, resolve omitted local bindings, preserve a dirty draft on Cancel, then apply a different request to the saved workflow. Target: under sixty seconds to the run confirmation, excluding model time. Explain that previous files remain changed and that this creates a new intent rather than replaying the old run.
5. **Recovery:** in an explicitly prepared isolated cancellation/Unknown scenario, request Stop, inspect the exact owned native session and inactivity proof, and explain why no generic Retry is offered. Release only if the existing service proves inactivity and an audit reason is supplied. An unrelated session must remain intact.

The facilitator must not silently complete difficult steps. Record each help request, wrong navigation, correction and misunderstanding. A failed safety decision is a failure requiring a fix or documented blocker, even if elapsed time meets its target. Three participants provide a small usability signal, not population-wide proof.
