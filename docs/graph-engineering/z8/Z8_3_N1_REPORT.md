## Not verified / limits

- No packaged-app, Windows or production-environment measurement. A source guard is wiring evidence, not a network measurement.
- CLI edits (two sites) and the Electron Main / `index.ts` wiring have source guards only; they could not be executed in the portable CI environment.
- Uncovered paths remain outside any claim: MCP, hooks, tools, raw sockets, explicit account/usage/sign-in/sync calls, conversation share, bots, other fetches not named in the matrix, and browser opens of community/docs links on request. Remote-workspace agents deployed by `packages/server` do not receive the Host variable and keep standalone behavior.
- `Feedback list/get` use an existing account token if present and are not blocked; the Feedback centre that exposes them is no longer reachable in Graph.
- The OTLP and ARMS positive-control limitations from Z8.1 are unchanged.
- The `ZCODE_AUTOMATIC_NETWORK_DENY` absent-means-standalone rule is a deliberate interpretation of "missing decision denies": a Host-launched Graph agent always receives the variable, while the standalone CLI (no product flavor) keeps its behavior.
