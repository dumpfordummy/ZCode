# Upstream merge checklist (Graph-relied native boundaries)

Use this whenever upstream ZCode is merged into the Graph fork. It is a checklist, not an instruction to merge now, and it lists only the files and contracts Graph depends on (derived in `Z8_3_R1_SPEC.md`). It is not a fork inventory.

## 1. Run first

```
pnpm typecheck
node --import tsx --test \
  packages/services/test/graphUpstreamContract.test.ts \
  packages/services/test/graphRuntimeComposition.test.ts \
  packages/services/src/graph-engineering/adapters/runtime-contract.test.ts \
  packages/services/src/graph-engineering/app/runtime-admission.test.ts \
  packages/services/src/zcode-agent/runtimeCapabilities.test.ts \
  apps/zcode-cli/packages/bootstrap/src/zcode-protocol-v4/native-contract.test.ts \
  apps/zcode-cli/packages/bootstrap/src/zcode-protocol-v4/interaction-registry.test.ts
```

All of these are already inside the required Cloud selectors (`services` group), so a merge PR that breaks a boundary fails `graph-cloud-required`. A red result means: stop and decide, do not edit the test to match. The only literals in the suite are in `FROZEN` (`graphUpstreamContract.test.ts`); changing one is a reviewed decision that also means re-reading the Graph code listed below.

## 3. Decisions a merge must make explicitly

- A new upstream capability that Graph should rely on: add it to `GRAPH_NATIVE_REQUIREMENTS`, to `FROZEN`, to the agent declaration and to this table in the same change.
- A renamed or removed method/command Graph uses: update Graph's call site, the requirement set and `FROZEN` together; never keep an alias just to satisfy the suite.
- A protocol or wire version bump: re-read `observation.ts`/`observer.ts` and the recipe/command parsers first; Graph's runtime check is an exact match by design.
- Files outside this table are not covered here (see the Z8 delta audit for the broader inventory).

## 4. Not covered

A live agent process, a packaged build and Windows are not exercised by these tests (`Z8_3_R1_SPEC.md`, Remaining unverified boundary).
