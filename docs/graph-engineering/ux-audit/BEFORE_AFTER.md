# Before and after (real screenshots)

**Before** = the checkout as found (`screenshots/audit/`, captured earlier in this work from the built Desktop app). **After** = the same app rebuilt with the implementation (`screenshots/after/`). Both come from the real Electron window with the controlled loopback provider; neither is a mock. The prototype (`screenshots/prototype/`) is a separate, synthetic design reference.

All "after" files exist at 1280×720 and 1920×1080 unless marked. Themes: Zai Dark unless the name says `light`; language: English unless the name starts `zh-CN-`.
