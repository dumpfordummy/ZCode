## 5. Decisions taken while implementing (all inside the approved scope)

1. The dialog action formerly called "Create workflow" is **Load into design** (it was one of three meanings of "Create workflow"); New run keeps **Review and run** and **Save as workflow only**.
2. A separate Built-in/Yours chip duplicated the label in the workflow selector and was removed; the kind is part of every option and of the New-run line.
3. Choosing a save target does not undo the review of an imported JSON (the template is the same); changing the target of **Save current design** does (its name and description defaults change).
4. **Open in Runs** stays available while a run owns the workspace: it only navigates.
5. A pin whose version number is offered with a **different digest** is treated as unavailable too (same class as a missing number), with its own message. A selection whose workflow is gone shows "Choose a workflow" instead of quietly selecting another.
6. Carrying references also carries `referencePolicy: "native-aware-v1"` when at least one reference was carried, because the flag belongs to those reference values. Nothing else internal is copied.
7. `pre-z8-u5-native` no longer calls `verifyU3Context` (it verifies editing of context bindings in the Workflows editor, not transfer) and selects the native instructions with the Context picker instead of the retired catalogue helper. The transfer assertions are unchanged. `pre-z8-u3-native` itself is untouched.

## 7. Not run / limits

- **Windows acceptance: NOT RUN.** **The four restored drivers: NOT RUN.** Real Windows Open/Save dialogs, real scaling 125% / 150% and the UX-M1 / UX-M2 open items (preflight-specific failure, lost response, disabled skill, cross-workspace Back to run, Host refusing a check save from a non-UI caller) are unchanged.

- `ux-m3-launch-manual.mjs --historical-run` (section 8) rewrites a real cancelled run's captured pin on disk and relaunches; it could not be executed here (no Electron). If the app refuses the rewritten record, that check is NOT RUN, not failed.
- Out of scope and not done: permission policy, pending-permission payloads, reviewer retry, concurrency, workflow search/tags, deleting workflows, cross-profile sync, automatic upgrade of historical pins, draft persistence across restart, the app-wide `html lang` change, packaging, release, Z8.
